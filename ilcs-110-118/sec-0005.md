# Sec. 5. Definition. In this Act, "institution" means, except for Illinois State University, Governors State University, Northeastern Illinois University, and Chicago State University, a public university in this State.
(110 ILCS 118/5)
(Section scheduled to be repealed on July 1, 2027)
(Source: P.A. 101-448, eff. 1-1-20; 102-187, eff. 1-1-22.)
