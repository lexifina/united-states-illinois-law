# Sec. 20. Quality and outcome measurement data.
(210 ILCS 155/20)
(a) For proper evaluation and monitoring of the program, each LTAC hospital must provide quality and outcome measurement data ("measures") identical to Medicare as specified in Medicare's LTCH Quality Reporting Program Manual (version 2.0) and any subsequent revisions.
(b) Two sets of measures must be calculated. The first set should only use data for medical assistance patients, and the second set should include all patients of the LTAC hospital regardless of payer.
