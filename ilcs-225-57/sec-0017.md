# Sec. 17. Social Security number on license application. In addition to any other information required to be contained in the application, every application for an original, renewal, reinstated, or restored license under this Act shall include the applicant's Social Security number.
(225 ILCS 57/17)
(Section scheduled to be repealed on January 1, 2027)
(Source: P.A. 97-514, eff. 8-23-11.)
