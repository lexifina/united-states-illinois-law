# Sec. 175. Violations. Unless otherwise specified, a person found to have violated any provision of this Act is guilty of a Class A misdemeanor for the first offense and a Class 4 felony for second and subsequent offenses.
(225 ILCS 106/175)
(Section scheduled to be repealed on January 1, 2031)
(Source: P.A. 89-33, eff. 1-1-96.)
